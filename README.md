# TidyQuote

A mobile-first residential cleaning quote calculator. Pricing settings are stored locally in the browser; the app has no account, backend, database, or analytics.

## Run locally

Requires Node.js 20 or newer.

```bash
npm install
npm run dev
```

## Checks

```bash
npm test
npm run check
npm run build
```

The production output is written to `dist/` and can be deployed to any static host such as Vercel, Netlify, or Cloudflare Pages.
